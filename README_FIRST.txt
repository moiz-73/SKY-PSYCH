WELCOME TO SKYPSYCH AI - READ ME FIRST
======================================

What it is (one sentence):
SkyPsych AI is a computer program that watches for signs of
tiredness and shows them as colored warning lights, like a
fatigue "check engine light" for an operator.

THE ONLY THING YOU NEED TO KNOW
-------------------------------
Do NOT type any commands. Everything is a double-click.
If a blue window asks a question, just press any key.

THE FILES, IN ORDER
-------------------
1. 00_SETUP.bat     Run this FIRST, one time only. It installs
                    the programs the demo needs and takes a few
                    minutes. Run it even if the folder looks ready.

2. 01_VALIDATE.bat  Run this once. It checks that everything is
                    working. At the end you should see
                    "VALIDATION COMPLETE".

3. 02_SIM_DEMO.bat  THE GUARANTEED DEMO. Needs NO camera. Shows a
                    simulated operator from GREEN to YELLOW to
                    RED, a microsleep alert, a coverage-loss
                    state, then recovery. Press Q or ESC in the
                    video window to end it.

4. 03_LIVE_CAMERA_DEMO.bat
                    Optional. Only if you have a webcam and want
                    to show the live version. If it does not
                    work, just use 02_SIM_DEMO.bat.

5. 04_PITCH_PACKAGE.bat
                    Opens the talking points and one-page pitch.

6. 05_HELP.bat      If anything fails or you are unsure.

PLEASE NOTE
-----------
This system is a simulation and demonstration tool. It is
advisory only. It is NOT certified aviation or medical
equipment and must not be used for safety-critical decisions.
