01 / Problem

Human error dominates aviation incidents

Fatigue degrades perception, judgment, and reaction time before procedural errors occur. It is invisible to the outside observer, unreliable when self-reported, and nearly impossible to catch by eye alone.

By the time a mistake is visible, the fatigue behind it has been building for minutes. The error is the symptom; fatigue is the cause. SkyPsych exists to make the cause visible.

02 / Solution

An ordinary camera becomes a cognitive telemetry sensor

SkyPsych AI reads involuntary micro-signals in the face — eyelid openness, blink rate and duration, eye-closure fraction (PERCLOS), and head-pose drift — and fuses them, in real time and locally, into a single 0–100 fatigue index.

No wearables. No specialized hardware. Just the webcam already in the room.

03 / Why Now

Computer vision, edge compute, and fatigue science have converged

Face-landmark models now run in real time on a laptop. Edge compute means the whole pipeline stays on-device. And decades of fatigue science establish the observable ocular and postural signals the index is built on.

This capability previously required expensive headsets or EEG. Today it is a software layer — and that changes who can deploy it and where.

04 / Product

A local-only, privacy-preserving HUD

An aviation-style display presents fatigue severity at a glance — GREEN normal, YELLOW rising fatigue, RED critical. A detected microsleep forces the highest alert immediately. When the operator is not visible, the system says so — it is never falsely green.

The interface is advisory. It reports an estimate; it performs no control actions, and it never claims to read a face it cannot see.

05 / Differentiation

Why SkyPsych is different

  • No headset. Only a camera already in the room.
  • No wristband. Nothing to charge, lose, or refuse to wear.
  • No cloud dependency. The entire pipeline runs locally in one process.
  • No raw frame storage. Frames exist transiently in memory; only abstract metrics persist.
  • Advisory, not replacement. It informs the human decision; it never replaces the operator.

07 / The Demo

45 seconds, every state, one laptop

The simulation runs the identical software on a deterministic 45-second timeline — no camera, no stored frames, same fusion, same HUD, same alerts.

GREEN
0–10s · Normal

Healthy operator. Alert baseline, normal blink dynamics.

YELLOW
10–20s · Rising

Fatigue signals rise. Slower blinks, longer closures, more head deviation — flagged early.

RED
20–26s · Critical

Critical fatigue. The moment a human should look and act.

MICROSLEEP
26–30s · Highest alert

Microsleep event. The operator briefly lost awareness; the system forces the highest alert.

NO_FACE
30–36s · Honest loss of signal

Operator not visible. The system says it cannot see them — it never pretends all is fine.

RECOVERY
36–45s · Return to normal

Recovery. Fatigue is dynamic — the reading returns toward normal.

08 / Privacy

Privacy is the architecture, not a patch

No Cloud

No network calls at runtime. Everything runs on the local machine.

No Stored Video

No raw frames, screenshots, or video persisted by default.

Abstract Telemetry

Exports are numbers only — blink rate, closures, head position, index. Nothing that reconstructs a face.

Advisory Only

Displays, chimes, logs. No control of any vehicle or system.

09 / Honesty

Advisory, early, and open about it

Honest Caveat

SkyPsych AI is an advisory research MVP. It estimates cognitive fatigue from an ordinary camera. It is not certified aviation equipment, not a medical device, and it does not prevent fatigue. Its rule-based index has not yet been validated at research grade against ground-truth measures, and it must never be used as the sole basis for a safety decision. It exists to make fatigue visible so a human can act sooner.
