# Presenter Final Checklist - SkyPsych Demo

One page. Everything is a double-click - no typing required.

---

## BEFORE (do these at least once before the day)

- [ ] Read `README_FIRST.txt` in the SkyPsych folder.
- [ ] Run `01_VALIDATE.bat` once - wait for **VALIDATION COMPLETE**.
- [ ] Run `02_SIM_DEMO.bat` once - confirm the video window opens, then press
      Q or ESC to close it.

## DURING (click order and narration cues)

1. Open the SkyPsych folder.
2. Double-click `02_SIM_DEMO.bat`. Say: "This is a simulated operator under
   fatigue monitoring."
3. **Green** - say: "Alert and normal."
4. **Yellow** - say: "Fatigue is rising - worth a break soon."
5. **Red** - say: "Fatigue is critical - action needed now."
6. **Microsleep** - say: "This long eye closure is the strongest alert."
7. **No face** - say: "The system honestly says it cannot see the operator
   rather than pretending everything is fine."
8. **Recovery** - say: "And the reading returns to normal."
9. When done, press **Q** or **ESC** in the video window to close it.
10. Optional: double-click `03_LIVE_CAMERA_DEMO.bat` to show the live webcam
    version, then Q or ESC to close.

## FALLBACKS (if anything goes wrong)

- **Camera fails** -> close it, use `02_SIM_DEMO.bat` (no camera needed).
- **Demo fails** -> double-click `04_PITCH_PACKAGE.bat` and keep talking from
  the pitch notes while it recovers.
- **Validation fails** -> run `00_SETUP.bat` once (a few minutes), then run
  `01_VALIDATE.bat` again.
- **Anything else** -> double-click `05_HELP.bat`.

## AFTER

- [ ] Close the demo window (Q or ESC).
- [ ] Thank the audience.
- [ ] Note any follow-up questions and who to send them to.
- [ ] Remind: advisory only - not certified aviation or medical equipment.
